**VOICE ENABLED NOTEPAD**

A python-based desktop GUI Application that fuctions similar to traditional Notepad but with added Speech-to-text and Text-to-Speech capabilities.
This application allows users to type, speak, listen to text, and manage text files through an easy-to-use graphical interface.

📌Project Overview

The voice enabled notepad is designed to enhance text editing by integrating voice interaction. It provides basic notepad features such as creating,opening and saving text files,along with advanced voice-based input
and output, making it useful for accessbility and productivity.

🚀 Features

1. Create new text documents.
2. Open existing .txt files.
3. Save text files.
4. Cut, copy, and paste text.
5. Convert written text into speech.
6. Convert spoken voice into text.
7. Simple and intuitive graphical interface.

🛠 Technologies Used and its purpose

Python -	Core programming language
Tkinter -	GUI development
pyttsx3	- Text-to-Speech conversion
SpeechRecognition - Speech-to-Text conversion
PyAudio -	Microphone input support
